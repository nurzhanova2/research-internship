# Код исследования

Пакет Python `xai_ews` и скрипты, которыми получены все данные, таблицы и графики практики.

| Папка | Что внутри |
| --- | --- |
| `src/xai_ews/data/` | загрузка сырых данных Fannie Mae, панель «кредит × квартал», метка Y1, макроданные, словарь признаков |
| `src/xai_ews/features/` | WoE и IV, стабильность (PSI), избыточность (корреляции, VIF, mRMR), важность (SHAP, перестановки, Boruta), отбор признаков |
| `src/xai_ews/models/` | скоринговая карта, CatBoost, XGBoost и LightGBM, нейросеть (PyTorch), калибровка |
| `src/xai_ews/evaluation/` | метрики, бутстреп и DeLong, ожидаемый убыток и список тревог, опережение тревоги, протокол оценки |
| `scripts/` | командные скрипты: загрузка и аудит данных, подбор гиперпараметров, обучение моделей |
| `configs/` | параметры данных, разбиения и признаков (YAML) |
| `tests/` | автоматические тесты (pytest) |

## Запуск

```bash
uv sync            # окружение Python 3.11 по uv.lock
uv run pytest      # тесты
```

Ноутбуки в папках недель выполнены и сохранены с результатами. Чтобы выполнить их заново, нужны исходные данные Fannie Mae Single-Family Loan Performance Data (скачиваются после регистрации на сайте Fannie Mae) в папке `data/raw/`; сами данные в репозиторий не входят.
