## О работе

Модель предсказывает **первый дефолт** (просрочка 90+ дней или закрытие по дефолту) в течение 12 месяцев у ипотечных кредитов, которые на дату наблюдения обслуживаются без просрочки. Используются открытые данные Fannie Mae по кредитам вместе с ценами на жилье, безработицей и рыночной ипотечной ставкой:

```text
данные Fannie Mae → панель «кредит × квартал» → метка первого дефолта → 59 признаков-кандидатов → 18 отобранных
→ скоринговая карта / CatBoost / XGBoost / LightGBM / нейросеть → калибровка и список тревог → замороженный протокол test → SHAP и LIME
```

Панель — 40,6 млн квартальных снимков 15 %-й выборки кредитов. Выборки разделены по времени: train — 2013–2015 гг., validation — 2016–2017 гг., test — 2018 г.; стресс-периоды — 2007–2009 гг., COVID 2019–2021 гг. и рост ставок 2022–2025 гг. Доля дефолтов 0,12–0,21 %, поэтому модели сравниваются по AUC, PR-AUC, калибровке, точности и полноте списка тревог (откалиброванная PD ≥ 1 %).

> [!WARNING]
> Test открыт второй раз — по новому протоколу, замороженному до открытия (первое открытие было в предыдущей постановке с двумя задачами); это названо ограничением. Опережение тревоги измеряется по квартальным снимкам и является грубой мерой. Модели — результат исследования, а не промышленная кредитная модель.

## Основные результаты

Test 2018: 3 758 886 наблюдений, 7 824 дефолта; список тревог — откалиброванная PD ≥ 1 %.

| Модель | AUC [95 % ДИ] | Кредитов в списке | Пойманных дефолтов | Пойманного убытка |
|---|---:|---:|---:|---:|
| Скоринговая карта B0 | 0,825 [0,819; 0,831] | 3,3 % | 22,6 % | 20,9 % |
| Нейросеть M2 | 0,834 [0,828; 0,839] | 3,7 % | 27,0 % | 27,1 % |
| **CatBoost M1** | **0,838** [0,832; 0,844] | 3,7 % | 27,6 % | 27,2 % |
| XGBoost | 0,839 [0,833; 0,845] | 4,2 % | 30,2 % | 30,6 % |
| LightGBM | 0,839 [0,833; 0,845] | 3,9 % | 29,1 % | 29,0 % |

- **H3 подтверждена:** динамические признаки добавляют +0,015 AUC [0,013; 0,017] и поднимают тревогу по 36 % будущих дефолтов вместо 26 %; медианное опережение — 10 месяцев.
- **H4 — частично:** вес по сумме долга сохраняет калибровку, но не повышает долю пойманного убытка (−0,5 п.п.). **H2** подтверждена, эффект мал.
- **Объяснения:** встроенный SHAP CatBoost не аддитивен для деревьев Depthwise глубже 2, поэтому используется точный SHAP методом перестановок; в кодах причин доминируют FICO и созаемщик; LIME согласен с SHAP в главном признаке, но менее устойчив (локальный R² 0,16).

Источники: [`comparison_table.csv`](Неделя_07_Базовые_модели/tables/test/comparison_table.csv), [`alert_capture.csv`](Неделя_07_Базовые_модели/tables/test/alert_capture.csv), [`h3_verdict.csv`](Неделя_07_Базовые_модели/tables/test/h3_verdict.csv), [`h4_verdict.csv`](Неделя_07_Базовые_модели/tables/test/h4_verdict.csv).

### 3. Воспроизвести результаты

- **Требования.** Python 3.11 и [uv](https://docs.astral.sh/uv/); окружение зафиксировано в `code/uv.lock`.
- **Без загрузки данных.** Тесты и рисунок сравнения моделей используют только файлы репозитория:

```bash
cd code && uv sync && uv run pytest
cd .. && uv run --project code python Неделя_07_Базовые_модели/code/fig_models.py
```

- **Из исходных данных.** Ноутбукам нужны данные Fannie Mae Single-Family Loan Performance Data (бесплатно после регистрации на сайте Fannie Mae) и публичные ряды FHFA, BLS и Freddie Mac; в репозиторий они не входят. Скрипты в `code/scripts/` загружают сырые файлы (`ingest_raw.py`), собирают панель (`build_panel.py`, `build_default_history.py`), проверяют ее (`audit_panel.py`, `leakage_check.py`), подбирают и обучают модели (`tune.py`, `fit_models.py`); затем ноутбуки воспроизводят все таблицы и рисунки.
